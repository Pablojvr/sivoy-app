# Delegar ajuste visual de SiVoy

Ejecuta un cambio visual pequeño bajo las reglas de
`@../rules/sivoy-estilos-delegados.md`.

Antes de editar, exige que el encargo incluya estos cinco datos:

1. Objetivo visual.
2. Archivos permitidos (máximo tres).
3. Archivos prohibidos o comportamiento que debe conservarse.
4. Criterios de aceptación y viewports relevantes.
5. Comando de validación.

Si falta un dato, solicítalo. Si el cambio requiere lógica o excede el alcance,
detente y devuelve el bloqueo sin modificar archivos adicionales.
